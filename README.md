# Cane & Camera — Static Photo Site

A clean, fast, SEO-friendly static site for fine-art photography.

## Templated build workflow

The repository now uses a small Python build step to generate static HTML pages from shared templates and JSON content:

- `build_site.py` renders:
  - `index.html`
  - `gallery.html` (wildlife)
  - `documentaries.html`
- Gallery images are rendered directly in HTML (SEO-friendly) with native lazy loading.
- Documentary cards are rendered from `data/documentaries.json` into static HTML.

## Commands

```bash
python3 build_site.py
./run.sh
```

## How to verify the changes locally

1. Generate pages from templates:
   ```bash
   python3 build_site.py
   ```
2. Start the local server:
   ```bash
   ./run.sh
   ```
3. Open the generated pages in your browser:
   - `http://localhost:8000/gallery.html`
   - `http://localhost:8000/documentaries.html`

### Quick checks

- Confirm gallery and documentary cards are present in page source (not inserted by JS).
- Confirm images include `loading="lazy"` attributes.
- Confirm lightbox behavior still works on gallery pages.

## Editing header and footer (single place)

Header and footer are defined in `build_site.py`:

- `render_header()`
- `render_footer()`

Those functions are injected into generated pages through `render_page()`. So if you change header/footer there and run:

```bash
python3 build_site.py
```

the generated pages (`index.html`, `gallery.html`, and `documentaries.html`) will all get the update automatically.

### Important exception: `about.html`

`about.html` is currently hand-maintained and is **not** fully generated by `build_site.py`.
So header/footer edits in `build_site.py` do **not** automatically update `about.html` right now; only link patching runs for that page.


## Image format guidance (performance)

Current build output serves responsive JPEG/PNG variants from `assets/img/gallery/generated/` with `srcset`, dimensions, and lazy loading.

If you want further performance gains without design changes, the next step is to extend the image pipeline to emit WebP/AVIF variants and wire them via `<picture>` in `build_site.py`. This repository does not yet include AVIF/WebP generation in the build script.
