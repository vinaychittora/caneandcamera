# Cane & Camera — Static Photo Site

A clean, fast, SEO-friendly static site for fine-art photography.

## Project structure

This repository is now maintained as direct static HTML files:

- `index.html`
- `gallery.html`
- `documentaries.html`
- `about.html`
- `landscapes.html`

Directory routes are also included as static pages:

- `gallery/index.html`
- `documentaries/index.html`
- `about/index.html`
- `landscapes/index.html`

## Commands

```bash
./run.sh
```

## Local preview

1. Start server:
   ```bash
   ./run.sh
   ```
2. Open pages in browser:
   - `http://localhost:8000/`
   - `http://localhost:8000/gallery.html`
   - `http://localhost:8000/documentaries.html`
   - `http://localhost:8000/about.html`
   - `http://localhost:8000/landscapes.html`
   - `http://localhost:8000/documentaries/`
